FinResolve

AI Complaint Routing & Priority Triage for CFPB Consumer Complaints

Built an end-to-end ML platform that ingests free-text consumer complaints from the CFPB's 1M+ row complaint database, routes each to the correct department with a fine-tuned DistilBERT classifier (9 categories), and assigns a priority level (critical / high / standard) using a TF-IDF + LightGBM pipeline trained on labels from a rule-based scoring system covering fraud keywords, legal references, and harassment signals. Reached 88% overall priority accuracy on a 203K-sample held-out test set. Deployed behind a FastAPI service with JWT auth and three role-based views (customer, department operator, and a reviewer queue for low-confidence predictions), containerized with Docker, with the BERT model versioned on AWS S3. Co-built as part of a graduate Applied Machine Learning course team project at George Washington University.

DC Metro Real-Time Arrivals Pipeline

Live Train Arrival Tracking Across All DC Metro Stations

Built a real-time data pipeline that polls the WMATA Metro API every 60 seconds across all DC Metro stations, storing roughly 580,000 arrival rows per day in PostgreSQL. An Express REST API serves deduped, latest-per-station arrivals to an auto-refreshing dashboard with color-coded line badges and station search. A separate Apache Airflow DAG runs daily to purge records older than 24 hours, keeping the database lean on a rolling retention window. The full stack — poller, database, API, dashboard, and Airflow — is containerized with Docker Compose and deployed on Railway.
